# Typography Reference Guide for Brand Guidelines

## Font Personality Chart

Use this to match font choices with brand personality.

| Brand Personality | Recommended Typeface Styles | Examples |
|------------------|-----------------------------|---------|
| Modern & Clean | Geometric sans-serif | Inter, DM Sans, Outfit, Plus Jakarta Sans |
| Professional & Corporate | Humanist sans-serif | Lato, Source Sans Pro, Nunito Sans |
| Bold & Powerful | Display / Grotesque | Barlow Condensed, Bebas Neue, Oswald |
| Elegant & Luxury | High-contrast serif | Playfair Display, Cormorant Garamond, EB Garamond |
| Friendly & Approachable | Rounded sans-serif | Poppins, Nunito, Quicksand, Fredoka One |
| Technical & Precise | Monospace / Tabular | JetBrains Mono, IBM Plex Mono, Space Mono |
| Creative & Artistic | Slab serif | Zilla Slab, Roboto Slab, Merriweather |
| Natural & Organic | Humanist serif | Lora, Crimson Text, PT Serif |
| Playful & Youthful | Display / Script | Pacifico, Lobster, Righteous, Lilita One |
| Minimal & Sophisticated | Thin/Light sans-serif | Raleway, Josefin Sans, Archivo |

## Recommended Google Font Pairings

These are battle-tested combinations. All available for free at fonts.google.com.

### Pairing 1 — Modern & Professional
- **Headline:** `Plus Jakarta Sans` (Bold, ExtraBold)
- **Body:** `Inter` (Regular, Medium)
- **Accent:** `Space Mono` (for code or data callouts)
- **Vibe:** Clean SaaS, fintech, productivity tools

### Pairing 2 — Elegant & Editorial
- **Headline:** `Playfair Display` (Bold, Black)
- **Body:** `Lato` (Regular, Light)
- **Accent:** `Cormorant Garamond` Italic (for pull quotes)
- **Vibe:** Luxury brands, editorial, fashion, high-end hospitality

### Pairing 3 — Bold & Energetic
- **Headline:** `Barlow Condensed` (ExtraBold, Black)
- **Body:** `Barlow` (Regular, Medium)
- **Vibe:** Sports, fitness, entertainment, consumer apps

### Pairing 4 — Friendly & Accessible
- **Headline:** `Nunito` (ExtraBold)
- **Body:** `Nunito` (Regular) or `Source Sans Pro`
- **Vibe:** Education, kids, nonprofits, community platforms

### Pairing 5 — Organic & Warm
- **Headline:** `Merriweather` (Bold)
- **Body:** `Source Sans Pro` (Regular)
- **Accent:** `Lora` Italic (for callouts)
- **Vibe:** Eco brands, wellness, food & beverage, artisan

### Pairing 6 — Minimal & Sophisticated
- **Headline:** `Josefin Sans` (Bold, Light)
- **Body:** `Raleway` (Regular)
- **Vibe:** Architecture, design studios, premium minimal brands

### Pairing 7 — Technical & Precise
- **Headline:** `IBM Plex Sans` (SemiBold)
- **Body:** `IBM Plex Sans` (Regular)
- **Accent:** `IBM Plex Mono` (code, data)
- **Vibe:** Developer tools, engineering, data companies

### Pairing 8 — Creative & Expressive
- **Headline:** `DM Serif Display` (Regular)
- **Body:** `DM Sans` (Regular, Medium)
- **Vibe:** Creative agencies, portfolios, art brands

## Line Height Guidelines

| Text Type | Recommended Line Height |
|-----------|------------------------|
| Display / Hero headlines | 1.0 – 1.15 |
| Section headings (H2–H3) | 1.15 – 1.3 |
| Subheadings (H4–H5) | 1.3 – 1.4 |
| Body text | 1.5 – 1.7 |
| UI labels / captions | 1.2 – 1.4 |
| Long-form articles | 1.6 – 1.8 |

## Letter Spacing Guidelines

| Context | Letter Spacing |
|---------|---------------|
| Display text (large headlines) | -0.02em to -0.04em (tighten) |
| Body text | 0 to 0.01em (default) |
| All-caps labels / tags | +0.08em to +0.15em (loosen) |
| Button text | +0.02em to +0.06em |
| Monospace / code | 0 (default) |

## Typography Don'ts Reference

1. **Never use more than 3 typefaces** in a single design system
2. **Don't mix two serifs** or two display fonts — combine contrasting styles
3. **Avoid decorative fonts for body text** — readability suffers
4. **Don't set long body text in all-caps** — it reduces reading speed by ~14%
5. **Avoid text below 12px** for any readable content (14px minimum for body)
6. **Don't stretch or condense** font letterforms manually — use condensed variants
7. **Avoid centered text for body copy** — reserve centering for short headlines
8. **Don't use justified text without hyphenation** — creates awkward word spacing

## Variable Fonts (Advanced)
Variable fonts allow a single font file to cover the entire weight/width spectrum. Excellent for performance and flexibility.

Recommended variable fonts:
- **Inter** — best all-around variable sans-serif
- **Plus Jakarta Sans** — modern, variable
- **Recursive** — personality-rich variable font
- **Raleway** — elegant variable sans-serif
- **Fraunces** — expressive variable serif

These reduce HTTP requests and allow fine-tuned intermediate weights (e.g., weight 550).
